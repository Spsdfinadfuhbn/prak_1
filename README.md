# Эмулятор командной строки UNIX-подобной ОС (GUI)

## 1. Общее описание
Данный проект представляет собой эмулятор CLI (интерфейса командной строки) с графическим интерфейсом пользователя (GUI), имитирующий работу терминала UNIX-подобных операционных систем. 

Вся работа с виртуальной файловой системой (VFS) происходит **исключительно в оперативной памяти компьютера**. При запуске программа считывает структуру указанной физической директории, загружает её дерево каталогов и содержимое текстовых файлов в RAM, после чего полностью изолируется от жесткого диска. Любые изменения состояния VFS (перемещение объектов, удаление папок) не затрагивают реальные файлы на компьютере.

## 2. Архитектура проекта и описание функций

Проект реализован на языке **Python** с использованием стандартной библиотеки **Tkinter** для построения GUI и не требует установки внешних зависимостей.

### Ключевые компоненты:
* **`VirtualFileSystem`** — класс ядра VFS, отвечающий за инициализацию структуры файловой системы в RAM, чтение файлов и трансляцию относительных/абсолютных путей в канонический вид (поддерживает переходы `.`, `..`).
* **`ShellEmulatorGUI`** — класс графической оболочки (REPL). Настраивает окно терминала, блокирует редактирование истории вывода (защита курсора), перехватывает нажатия клавиш и выводит кастомное приглашение к вводу (Prompt).

### Основные функции и методы:
* `_load_from_disk(root_path)` — рекурсивный обход физической директории и построение её точной копии в оперативной памяти.
* `_resolve_path(path)` — валидация и трансляция путей в канонические абсолютные узлы структуры VFS.
* `parse_arguments(cmd_line)` — токенизация входной строки и раскрытие переменных окружения реальной ОС (например, `$HOME`, `$USER`).
* `execute_command(cmd_line)` — диспетчер (маршрутизатор) команд на базе паттерна «Таблица переходов» (Command Map) с жестким ограничением длины методов (до 40 строк кода).
* `run_start_script()` — чтение и последовательное выполнение команд из стартового автоматизационного скрипта с имитацией ввода-вывода и **немедленной остановкой при первой ошибке**.

### Поддерживаемые команды:
* `ls` — просмотр содержимого текущей или указанной виртуальной директории.
* `cd` — изменение текущего рабочего каталога (поддерживает абсолютные и относительные пути).
* `pwd` — вывод абсолютного пути текущего рабочего каталога в VFS.
* `tail` — вывод последних строк текстового файла (поддерживает флаг `-n` для регулирования количества строк, по умолчанию — 10).
* `rmdir` — валидация и безопасное удаление пустой папки VFS в памяти (с проверкой на заполненность каталога и запретом на удаление корня `/`).
* `mv` — перемещение или переименование виртуальных файлов и целых поддеревьев директорий в RAM.
* `exit` — завершение работы эмулятора и закрытие графического окна.

## 3. Настройки и аргументы запуска

При запуске эмулятора в консоль реальной ОС выводится отладочный лог со всеми заданными параметрами конфигурации.

### Параметры командной строки:
* `--vfs` (обязательный) — физический путь к директории на диске, которая станет источником для VFS.
* `--prompt` (опциональный) — формат пользовательского приглашения к вводу (поддерживает динамический тег `{dir}`). По умолчанию: `[user@vfs {dir}]$ `.
* `--script` (опциональный) — путь к стартовому скрипту эмулятора для автоматического тестирования команд.

## 4. Сборка проекта и запуск

### Запуск эмулятора:
Для запуска графического интерфейса передайте обязательные параметры через терминал вашей ОС:

```bash
# Пример запуска в Linux / macOS
python3 emulator.py --vfs "./my_virtual_root" --prompt "vfs_root:{dir} \$> " --script "./start.sh"

# Пример запуска в Windows
python emulator.py --vfs ".\my_virtual_root" --prompt "vfs_root:{dir} \$> " --script ".\start.sh"
```

### Запуск автоматических тестов:
В проекте реализовано полное покрытие бизнес-логики модульными тестами (юнит-тестами), проверяющими корректность разбора путей, раскрытия переменных, а также обработку ошибок для всех команд эмулятора.

Для запуска тестирования выполните команду:
```bash
python -m unittest test_emulator.py
```
